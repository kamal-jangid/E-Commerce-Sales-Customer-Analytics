# 📊 E-Commerce Sales & Customer Analytics

## 📌 Project Overview
This project focuses on analyzing e-commerce sales and customer data to identify business insights, sales trends, and product performance.

The goal is to understand business performance through data analysis and interactive dashboards.

## 🎯 Project Objectives
- Analyze overall sales and profit.
- Identify top-performing products and categories.
- Understand customer segments.
- Analyze regional sales performance.
- Identify monthly and yearly sales trends.

## 🛠️ Tools & Technologies
- Microsoft Excel
- SQL (MySQL)
- Python (Pandas, NumPy)
- Power BI

## 📂 Dataset
**Dataset:** Global Superstore Dataset

The dataset contains information about orders, customers, products, sales, profit, discounts, and regions.
